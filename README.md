# 玲珑调音 · Prima Tune

> 安卓端「**语音合成调参台**」：把 **调参 → 请求 → 试听 → 留存** 收进一个 App。
> **兼容十余家 TTS 厂商**（＋本机系统 TTS ＋自定义渠道）与**多家 LLM**；**无中转服务器**，数据只在本机。

## ✨ 特色（为什么用它）

- **自定义拉满**：64 套配色主题 · 壁纸（可二次取景 / 浓度）· App 图标与桌面入口 · 字号档位 · 界面语言（中/英/日/韩）· 音色 · 提示词 —— 都能改，且**永远可一键回默认**。
- **界面美观**：语义色槽 ＋ 成套形状质感；点按水波 / 留痕、指示符动效、纯淡入转场等细节统一打磨。
- **多家 TTS / LLM 兼容**：阿里云百炼 · OpenAI · Groq · Step · xAI · ElevenLabs · MiniMax · Fish Audio · Gemini · MiMo · B 站 IndexTTS · **本机系统 TTS** · **自定义渠道**；LLM（润色 / 翻译）兼容 OpenAI 格式的多家（千问 / DeepSeek / 豆包 / GLM / Kimi / OpenAI…）。
- **内置翻译 & AI 润色**：一键把文本**翻成多语言**（Google / MyMemory 双源自动回退）；也可让 AI **润色成"适合朗读"的稿子**。
- **自动"提示工程"，提高还原度**：自动为 TTS 生成 **风格指令（自然语言）＋ 情感 / 拟声标签（audio tags，如 `[whisper]`）**；厂商 / 模型 / 支持参数由**软件先查好再拼进请求**，让合成**更像、更准**。（发音纠错表 `hot_fix` 是 TTS 侧参数，**不归「智能填参」管**，需要时手填。）
  - 术语：这套做法业界叫 **prompt engineering for TTS** ／ **audio tags / paralinguistic cues** ／ **hot-fix（发音纠正）**。
- **非破坏 · 可回退**：每个自定义项都有"恢复默认"；**源码全开源**。

## 🚀 快速上手

1. 打开 App → 右上角「**设置**」→ 选厂商、粘贴 **API Key**（**仅存本机**；本机系统 TTS **免 Key**）。
2. 选音色（或用「**＋ 建音色**」上传样本，做**声音复刻**）。
3. 输入文本 / 情绪指令 → **生成**；记录卡可 **播放 / 回填参数 / 分享 / 下载**。

> 首次安装会让你**先选界面语言**（中 / 英 / 日 / 韩）。

## 🎧 支持

- **TTS**：见上（十余家 ＋ 系统 TTS ＋ 自定义渠道）；**输出格式按厂商自动过滤**（不可能选的就不显示）。
- **LLM**（润色 / 翻译）：千问 · 百炼 / DeepSeek / 豆包 / GLM / Kimi / OpenAI / 自定义。

## 🔒 隐私与红线

- **零预置密钥**：Key 由用户自填，**仅存本机 App 私有空间**。
- **无中转服务器**：请求**由你的设备直连所选厂商**；文本除发给所选厂商外**不上传**。
- 历史记录 / 音色 / 壁纸等**全部只在本机**。

**v1.6.4**
- **修「已准备语音，到点却响系统铃声」（关键 bug，用户 2026-10-09 报）**
  - **根因**：设完闹钟会**立刻**预生成一次；若离响铃很近，那条"提前 3 小时"的预生成闹钟会被排到 **now+60 秒** → **60 秒时又跑一次预生成，把刚做好的语音删掉重做** → 到点缓存正好是空的 → 只能响系统铃声。所以"设置页显示已准备 1 段"和"到点响系统铃声"**同时成立**。
  - **三处修复**：① 预生成**不再一上来就删旧语音**（先写 `alarm/tmp/`，**全部成功后才一次性替换**）→ 任何时刻都有可播缓存；② 加**跨实例生成锁**（`generating`）→ 两次生成不再互相删档；③ **离响铃太近时不排预生成闹钟**（保存那次已经生成；到点若没好，响铃流程**轮询等 30 秒**再切人声）。
  - 另：设的闹钟**离响铃不到 5 分钟**时，保存后**如实提示**"语音可能来不及，到点会先响系统铃声"。
- **修「全屏响铃页不弹」**：安卓 14+ 起「**全屏通知**」权限**默认不授予**（只给电话/闹钟类系统应用）→ `setFullScreenIntent` 被降级成横幅通知；后台 `startActivity` 也被系统拦。现在**保存闹钟时自动检测并引导开启**；响铃时把"直接拉起成功/被拦、全屏权限开没开"写进 `status.txt` 便于排查。
- **闹钟入口 / 动作行配色**：按《夕汀前端规范》⑥ 采用 **accent 描边档（空心）** —— 面色 `accent` 10% / 描边 `accent` 60%、字取 `accent`、圆角取 `btnRadius`（用户 2026-10-09 指定这一档，不再随 `solidBtn` 变）。

**v1.6.2**
- **闹钟「权限体检」改成引导式**（照姊妹项目**闪译**的做法）：把国产 ROM 必做的**三步**放在最上面，逐项 ✓/✗、点一下直达系统设置：
  **① 最近任务 🔒 锁定　② 省电策略 → 无限制　③ 自启动 → 开启**；下面再列权限清单（精确闹钟 / 通知 / 全屏响铃 / 电池优化），底部一个「打开应用详情」。
- **结论（读闪译代码得出）**：闹钟要准点响，靠的**不是常驻、也不是无障碍**，而是**"允许系统在后台把本应用拉起来"**——这正是小米「自启动」的定义。它**不常驻、不占内存、不额外耗电**，只在被唤醒那一刻生效。
  - 顺带说明：闪译真正靠的是**无障碍服务**（系统托管、被清理后自动重绑），对闹钟来说**又重又没必要**（还会带来下面那个副作用）。
- **找出闪译「音量键卡顿」的根因**：无障碍配置里的 `flagRequestFilterKeyEvents`（为拦返回键而开）会让系统把**所有物理按键**都先路由给无障碍服务 → 音量键一按就迟滞。玲珑调音**不使用无障碍服务**，因此没有这个问题。
